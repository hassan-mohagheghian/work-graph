# Frontend Routing & Navigation Plan

## Overview

Restructure the Next.js App Router to match the required canonical routes, add a shared project layout with tab navigation, and reorganize the roadmap view with expandable milestones and drag-and-drop support.

---

## 1. Backend API Mapping (existing endpoints)

All routes are under `apps/backend/src/modules/*/api/`. The frontend builds around these:

| Backend Prefix | Key Endpoints | Frontend Consumer |
|---|---|---|
| `/organizations` | `GET /`, `GET /{id}`, `POST /`, `GET /{id}/members`, `POST /{id}/members`, `DELETE /{id}/members/{uid}`, `PATCH /{id}/members/{uid}` | Org pages |
| `/projects` | `GET /org/{orgId}`, `POST /`, `GET /{id}/members`, `POST /{id}/members`, `PATCH /{id}/members/{uid}`, `DELETE /{id}/members/{uid}` | Project pages |
| `/tasks` | `GET /`, `GET /project/{pid}`, `GET /{id}`, `POST /`, `PATCH /{id}`, `DELETE /{id}` | Task pages |
| `/roadmaps` | `GET /`, `GET /{id}`, `POST /`, `PATCH /{id}`, `DELETE /{id}`, `POST /{id}/activate` | Roadmap tab |
| `/milestones` | `GET /roadmap/{rid}`, `GET /{id}`, `POST /`, `PATCH /{id}`, `DELETE /{id}`, `POST /roadmap/{rid}/reorder` | Milestone views |
| `/documents` | `GET /`, `GET /{id}`, `POST /`, `PATCH /{id}`, `DELETE /{id}`, `POST /{id}/attachments`, `DELETE /{id}/attachments/{aid}`, `GET /{id}/attachments/{aid}/download` | Documents tab |
| `/auth` | `POST /login`, `POST /logout`, `GET /me` | Auth |

## 6. Roadmap Page Design

The roadmap page (`/projects/:pid/roadmap`) displays milestones as expandable/collapsible sections.

### Components

- **RoadmapView** (`src/features/planning/components/roadmap-view.tsx`) - main container
  - Fetches roadmaps for the project
  - Selects the active roadmap
  - Renders list of `MilestoneSection` components

- **MilestoneSection** (`src/features/planning/milestone/components/milestone-section.tsx`)
  - Uses `Collapsible` (shadcn/ui) for expand/collapse
  - Shows milestone title, status badge, task count
  - When expanded: shows tasks within the milestone
  - Each task links to canonical `/projects/:pid/tasks/:tid`
  - Drag handle for reordering (using `@dnd-kit/core` + `@dnd-kit/sortable`)

- **MilestoneTaskList** (`src/features/planning/milestone/components/milestone-task-list.tsx`)
  - Lists tasks belonging to the milestone
  - Each task is a `SortableTaskItem` wrapped in dnd-kit

### Drag-and-Drop

Install `@dnd-kit/core` and `@dnd-kit/sortable`. The reorder action calls `POST /milestones/roadmap/{roadmapId}/reorder` with the new ordered IDs.

```tsx
// In MilestoneSection
<Collapsible>
  <CollapsibleTrigger>
    <GripVertical /> {/* drag handle */}
    <span>{milestone.title}</span>
    <Badge>{milestone.status}</Badge>
    <ChevronDown />
  </CollapsibleTrigger>
  <CollapsibleContent>
    <MilestoneTaskList milestoneId={milestone.id} />
  </CollapsibleContent>
</Collapsible>
```

- Each row links to `/projects/:pid/tasks/:taskId`
